# learn-japanese

Голосовой агент для изучения японского: тренажёр чтения каны/кандзи на
скорость с мгновенным распознаванием речи и проактивный разговорный
собеседник на базе OpenAI Realtime, с повторением по кривой забывания (FSRS).

Статус: **работает MVP drill-режима** — хирагана и катакана на скорость,
повторения по FSRS, прогресс в браузере ([устройство](docs/DRILL.md)).
Распознавание делает Vosk локально, декодер ограничен **одной ожидаемой
морой**: задержка 371–475 мс, распознавание 75–90 %, ложных срабатываний нет
([спайк №2](docs/SPIKE-ASR-VOSK.md); Web Speech API отклонён
[спайком №1](docs/SPIKE-ASR.md)). Дальше — разговорный режим.

## Быстрый старт

```bash
bun install
bun run fetch:model   # модель Vosk, 48 МБ, один раз
bun run dev
```

Открыть http://localhost:5173 в Chrome и произнести показанный символ.

- `?mock=1` — без микрофона, ответы с клавиатуры ромадзи.
- `?lab=1` — лабораторный стенд из спайка №2: ручки декодера, сырые гипотезы,
  JSON-отчёт. Нужен, чтобы перемерить распознавание на новом устройстве.
- Для телефона нужен https: `bun run dev:https`, подробности в
  [docs/SPIKE-ASR.md](docs/SPIKE-ASR.md).

Тесты и типы:

```bash
bun test && bun run typecheck
```

## Как работать с репозиторием

Проект разрабатывается в двух окружениях:

- **Облако (Claude Code on the web)** — проектирование, скелет кода, логика,
  тесты, документы. Изменения приходят ветками/PR в этот репозиторий.
- **Локально** — всё, что требует микрофона, звука и реальных устройств
  (drill-режим, Realtime-разговор). Клонировать в рабочую директорию:

```bash
git clone git@github.com:sergeiavoroshilov/learn-japanese.git ~/Development/learn-japanese
cd ~/Development/learn-japanese
```

Рантайм — [Bun](https://bun.sh): `curl -fsSL https://bun.sh/install | bash`.
